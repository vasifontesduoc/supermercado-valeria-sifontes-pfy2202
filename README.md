# 🛒 SuperMercado – Gestión de Inventario

Sitio web desarrollado en **React** para la gestión de inventario de un supermercado

## Funcionalidades

- **Inicio:** tabla de inventario con buscador por producto o categoría, resumen de stock y estado de cada producto (Disponible / Stock bajo / Agotado).
- **Quiénes somos:** misión, visión y valores del supermercado.
- **Contáctanos:** datos de contacto y formulario.
- **Menú inferior** para navegar entre las páginas sin recargar el sitio.

## Tecnologías

- React
- React Router (`BrowserRouter`, `Routes`, `Route`, `NavLink`)
- HTML, CSS y JavaScript

## Rutas

| Ruta             | Página        |
|------------------|---------------|
| `/`              | Inicio        |
| `/quienes-somos` | Quiénes somos |
| `/contactanos`   | Contáctanos   |
| `*`              | Página 404    |

## Cómo ejecutarlo

```bash
npm install
npm start
```

Luego abrir http://localhost:3000
